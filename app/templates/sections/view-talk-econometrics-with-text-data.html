Econometrics with text data

NLP, Sentiment & Alt Data — CQF Talks

What This Talk Covers

The econometrics of text: transforming qualitative sentiment into quantitative variables with valid inference — measurement error, generated regressors and identification with text data.

Plain English Notes

The Big Picture: A sentiment index is an estimate pretending to be data: regressions using it inherit its noise. Text econometrics supplies the corrections that keep t-statistics honest when the regressor came from a language model.

Core Mathematics

Generated-regressor correction
$$\hat{\text{Sent}} = \text{Sent} + \eta \;\Rightarrow\; \text{s.e.}(\hat\beta) \text{ must reflect } \eta$$
